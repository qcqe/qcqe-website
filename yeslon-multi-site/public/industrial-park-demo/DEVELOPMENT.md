# 工业园区全维度智慧监管平台 DEMO 开发文档

## 一、设计目标

构建一套覆盖工业园区 **电气安全、配电监测、能源管理、环境监控、AI诊断、运维管理** 六大维度的全功能在线演示平台。

对标 BusBMS 母线监测 DEMO（216KB 完整交互系统），本 DEMO 在广度和深度上均需超越。

## 二、功能模块架构

| 模块 | 子功能 | 数据来源 |
|------|--------|---------|
| 🏭 园区总览 | 综合态势看板、告警统计、在线率、健康评分 | ESA/ESB/ESF 等 |
| ⚡ 配电监测 | 配电室、配电柜、变压器、UPS 实时数据 | ESA/ESB/FECB |
| 🛡️ 电气安全 | 漏电监测、温度监测、电弧检测、绝缘监测 | ESF/EST/FA/FR |
| 🌩️ 防雷监测 | SPD 状态、雷电流、接地电阻、等电位 | FS/FSS/FL/FR/FG |
| 📊 能源管理 | 能耗统计、碳排放、功率因数、分项计量 | ESA/FEXLINK |
| 🤖 AI 诊断 | 健康评分、故障预测、寿命预测、谐波分析 | 太一AI引擎 |
| 🔔 告警中心 | 实时告警、历史告警、知识库、工单管理 | 规则引擎 |
| 📹 视频监控 | 摄像头实时画面、周界报警、AI识别 | 集成接口 |
| 🌡️ 环境监测 | 温湿度、水浸、烟感、气体、气象 | 环境传感器 |
| 🔧 设备管理 | 设备台账、巡检计划、维护记录、OTA升级 | 全系列产品 |
| 📋 报表中心 | 日报/周报/月报、自定义报表、导出 | 数据分析引擎 |
| ⚙️ 系统设置 | 用户权限、告警阈值、通知配置、日志 | 平台管理 |

## 三、技术指标

- 监测参数：260+ 个电气参数
- 在线节点：200+ 个
- 数据刷新：≤5 秒
- AI 预测精度：≥94%
- 告警响应：秒级
- 历史存储：≥3 年

## 四、UI/UX 设计规范

- 色彩方案：深色主题（参考 BusBMS DEMO）
- 交互方式：侧栏导航 + 页面切换
- 数据可视化：ECharts 风格图表
- 响应式：适配 1920×1080 大屏

## 五、技术选型

- 纯前端 HTML + CSS + JavaScript
- Canvas 图表渲染
- 模拟数据 + 定时刷新
- SEO 标签 + Geo 检测
