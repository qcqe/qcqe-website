# Getting Started with Yeslon Multi-Site

This is a multi-site platform built with React, TypeScript, and Vite.

## Available Scripts

In the project directory, you can run:

### `npm install`

Install all dependencies.

### `npm run dev`

Runs the app in development mode.

### `npm run build`

Builds all sites for production.

## Project Structure

- `packages/` - Shared packages (components, SEO, Geo, etc.)
- `sites/` - Individual site configurations and data
- `scripts/` - Build and deployment scripts
- `docs/` - Documentation
