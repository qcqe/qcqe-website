## 一、软文撰写结构规范（V2.1 固化）

### 认知顺序（不可颠倒）
**概念 B 定义 + 小表 → 一张总对比表 → 品牌叙事 → 互补结论 → 方案分层**

避免读者刚理解概念就被品牌打断。

### 14 块推荐结构

| 块 | 名称 | 保留建议 |
|:---:|:---|:---|
| 0 | 刊头 / 系列信息 | 连载必用；单篇可省略 |
| 1 | 开篇场景 + 核心追问 | 【建议保留】3～5秒让读者觉得"这说的就是我" |
| 2 | 破除误解（1～2句） | 【建议保留】降低防御心理 |
| 3 | 概念 A：在回答什么问题 | 如"抄表=计量与结算" |
| 4 | 概念 A 的边界 | 自然引出"为什么不够" |
| 5 | 概念 B：定义 + 具象化 | 【建议保留】物理量｜运维价值 小表 |
| 6 | 一张总对比表 | 【建议保留】含决策用途行；品牌段之前 |
| 7 | 品牌与叙事（克制） | ※ 公司全称+定位+愿景各出现一次即可 |
| 8 | 互补结论 | 明确写"互补、各司其职"，不树敌 |
| 9 | 方案分层（感知—边缘—平台） | 【建议保留】对外稿仅用文字分层，不用ASCII |
| 10 | 「一层一块」的落地 | 写清网关型测控器可覆盖感知+上送 |
| 11 | 产品事实块（分型号条列） | 【建议保留】只写说明书有的值 |
| 12 | 分角色「一句话」 | ※ 管理者/运维优先；禁续费率/中标率话术 |
| 13 | 结语 + 记忆句 | 【建议保留】8～16字对仗短句 |
| 14 | 免责声明 | 【建议保留】独立成段 |

## 二、执行纪律（红线）

### 公司名称
- 正文至少一次全称：**微物联技术（深圳）有限公司（FEXLINK / 易视通）**

### 通讯表述
- **禁止**用"无线通信能力"一笔带过
- **须写**：「上行通讯（如 4G / 以太网 / RS485，以说明书为准）」

### 产品参数（强约束）
- **仅说明书或对外规格书逐字有的才能写**
- 内部汇总表仅有"电能计量"时，**不得**擅自加"多费率电量累积"
- 温度路数写"4 路温度监测"即可，**勿**加"NTC"等除非公开资料明确

### 平台能力
- 只列资料已写明项
- 告警规则、推送渠道写「以平台版本与合同附件为准」，**不写死**

### 物数据小表价值列
- 优先中性工程表述（如"电能质量问题""可能影响敏感设备与器件温升"）
- **慎用**"污染""加速老化"等除非有引用依据

## 三、标题写法规范

| 类型 | 结构提示 |
|:------|:----------|
| 追问式 | XXX 到底是什么？和 YYY 有何本质区别 |
| 破除误解式 | 能 A 不等于能 B |
| 成本代入式 | 电费里有多少花在 … |

| 清单式 | N 个信号 / N 类隐患 |

## 六、文前 / 文后固定格式（发布体例）

### 文首顺序
1. **一级标题 H1**（与对外标题完全一致）
2. **刊头 blockquote**：公司全称 + 定位 ｜ 系列名 · 第 N 篇
3. **摘要 blockquote**（1～3句：场景 + 本文回答的问题 + 读者收益）
4. **信息来源加粗段**：涉及型号、资料性质；不构成承诺；以国标/说明书为准
5. `---` 分隔线后进入开篇

### 文尾顺序
1. 结语（记忆对仗句 + 第一步式收束）
2. `---`
3. **免责声明**（独立段，加粗标题）

## 七、文件命名与版本流转

| 文件名关键词 | 含义 | 是否对外 |
|:----------|:------|:----------|
| 初稿 / 讨论稿 | 内部任意命名 | 否 |
| **终稿** | 结构素材齐备，可能含 ASCII | 否 |
| **规范版** | 收紧事实与通讯表述的简版 | 可对外（偏短） |
| **发布定稿** | 按第八节体例与第六节清单勾选完毕；无 ASCII | **是（唯一对外源）** |

流转：`初稿 → 终稿（可选）→ 规范版校对 → 发布定稿`

## 八、成稿前自检清单（每次必勾）

- [ ] 开篇是否为**场景 + 追问**？
- [ ] 概念 A 与概念 B 是否**各写清边界**？
- [ ] **概念 B 小表** + **总对比表**是否齐全？总对比表是否在**品牌段之前**？
- [ ] 是否写清**互补**而非替代？
- [ ] 方案是否用**感知—边缘—平台**讲清？
- [ ] 对外稿（微信/PDF/Word）是否已**删除 ASCII**？
- [ ] 产品参数是否**逐条可对说明书**？无资料外发挥？
- [ ] 通讯是否使用规范表述，无「无线能力」歧义？
- [ ] 分角色段是否**无销售指标话术**？
- [ ] 是否有**文前信息边界**与**文末免责声明**？
